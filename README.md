
# 📚 Book Price Analyzer

A web scraping and data analysis project developed with Python.

## Project Overview

This project collects book titles and prices from the Books to Scrape website and analyzes the collected data through an interactive web dashboard.

## Features

- Collect book titles and prices from a website.
- Analyze book prices using Pandas.
- Calculate average, minimum, and maximum prices.
- Display interactive charts using Plotly.
- Search books by title.
- Download collected data as a CSV file.
- Refresh data from the source website.

## Technologies Used

- Python
- Streamlit
- BeautifulSoup
- Requests
- Pandas
- Plotly

## Data Source

[Books to Scrape](https://books.toscrape.com/)

## Installation

Install the required libraries:

```bash
pip install -r requirements.txt
```

## Run the Application

```bash
streamlit run app.py
```
